## 작업
- TDD 단계별 To-Do 목록을 SPEC, RED, GREEN, REFACTOR, 최종 제출로 정리한다.
- 완료된 SPEC 항목과 대기 중인 RED/GREEN/REFACTOR 항목의 체크 상태를 정확히 맞춘다.
- 각 TODO 항목이 `.ai/prompts/README.md`의 프롬프트 목록과 대응되는지 확인한다.
