# skills/README.md

## 개요

반복 작업을 안정적으로 수행하기 위한 프로젝트 전용 작업 절차를 모아두는 디렉토리이다.
테스트 케이스 작성, 코드 리뷰, BP.md 작성, 발표 자료 정리처럼 여러 번 반복되는 업무를 스킬 문서로 분리한다.

---

## 예정 스킬

| 파일 | 목적 |
|---|---|
| `skill_test-case.md` | RED/GREEN 단계 테스트 케이스 작성 절차 |
| `skill_code-review.md` | PR 리뷰 및 결함 탐지 체크리스트 |
| `skill_bp-writing.md` | 최종 BP.md 6장 구조 작성 절차 |
| `skill_session-close.md` | 세션 종료 시 sessions/logs 저장 절차 |

---

## 작성 규칙

각 스킬 문서는 아래 구조를 따른다.

```markdown
# {스킬명}

## 사용 시점

## 입력 자료

## 작업 절차

## 완료 기준

## 주의사항
```

---

## 운영 규칙

- 스킬 문서는 실제 작업 중 반복된 절차가 확인되었을 때 추가한다.
- 아직 검증되지 않은 절차는 TODO 또는 메모로 남기고 완료 규칙으로 확정하지 않는다.
- 스킬 문서의 완료 기준은 `TODO.md`의 체크 항목과 연결되도록 작성한다.
