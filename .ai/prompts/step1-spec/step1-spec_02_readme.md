## 작업
- `README.md`에 프로젝트 개요, 실행 방법, 테스트 방법, 주요 문서 링크를 정리한다.
- To-Do 상세 상태는 `TODO.md`를 기준으로 삼고 README에는 요약만 둔다.
- 현재 TDD 상태가 SPEC 완료, RED/GREEN/REFACTOR 대기임을 반영한다.

## 제약
- 문서 변경만 수행한다.
- 커밋은 가능한 50줄 이하 단위로 분리한다.
- pytest 실행이 필요한 변경은 아니지만, 실행하지 않았다면 명시한다.
- 커밋 메시지 형식: `docs: update README`
