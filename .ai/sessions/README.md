# sessions/README.md

## 개요

세션별 작업 컨텍스트를 저장하고 복원하는 파일 관리 규칙이다.
새 세션에서 이전 작업을 이어가려면 해당 단계의 최신 세션 파일과
current.md 를 AI CLI 에 전달한다.

---

## 디렉토리 구조

```
sessions/
├── current.md                          # 최신 세션 컨텍스트 (항상 최신 유지)
├── step1-spec/
│   └── step1-spec_session_01.md
├── step2-red/
│   ├── step2-red_session_01.md
│   └── step2-red_session_02.md
├── step3-green/
│   └── step3-green_session_01.md
└── step4-refactor/
    └── step4-refactor_session_01.md
```

---

## 세션 파일 구조

각 세션 파일은 아래 구조를 따른다.
파일명의 `{번호}`는 `01`, `02` 형식의 2자리 순번을 사용한다.

```markdown
# {단계}_{세션번호} | {날짜}

## 단계
현재 TDD 단계 (예: step2-red)

## 완료 항목
- [x] 완료된 TODO 항목 목록

## 미완료 항목
- [ ] 다음 세션으로 이월된 TODO 항목 목록

## 다음 시작 프롬프트
"{프롬프트 파일명} 진행" 형식으로 다음 작업을 명시

## 파일 변경 내역
- 신규/수정된 파일 목록

## 커밋 메시지 목록
- 이번 세션에서 사용한 커밋 메시지 목록

## 이슈 및 메모
- 발생한 이슈, 결정 사항, 다음 세션 주의사항
```

## 세션 종료 시 — 컨텍스트 저장 프롬프트

세션 종료 전 아래 프롬프트를 AI CLI 에 입력하여 컨텍스트 파일을 생성한다.

```
현재 세션의 컨텍스트를 아래 규칙에 따라 저장한다.

저장 경로:
- .ai/sessions/{현재단계}/{현재단계}_session_{번호}.md
- .ai/sessions/current.md (동일 내용으로 덮어쓰기)

파일 구조는 .ai/sessions/README.md 의 ## 세션 파일 구조 를 따른다.

포함 내용:
1. 이번 세션에서 완료한 TODO 항목 (.ai/prompts/README.md 기준)
2. 미완료 항목 및 이월 사유
3. 다음 세션 시작 프롬프트 파일명
4. 변경된 파일 목록 (python/ 기준)
5. 커밋 메시지 목록
6. 발생 이슈 및 결정 사항
```

---

## 새 세션 시작 시 — 컨텍스트 복원 프롬프트

새 세션 시작 시 아래 프롬프트를 AI CLI 에 입력한다.

```
아래 파일을 읽고 이전 세션의 작업을 이어서 진행한다.

참조 파일:
- .ai/sessions/current.md
- .ai/prompts/README.md
- .ai/TODO.md
- docs/PRD.md

확인 후 current.md 의 ## 다음 시작 프롬프트 항목에 명시된
프롬프트 파일명으로 작업을 시작한다.
```

---

## current.md 운영 규칙

- 세션 종료 시마다 최신 세션 파일 내용으로 덮어쓴다.
- 단계가 바뀌어도 current.md 는 항상 단일 파일로 유지한다.
- 세션 파일은 누적 보관하고 삭제하지 않는다.
