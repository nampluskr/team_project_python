### 과정 개요

본 과정은 SW 개발자를 대상으로 AI를 활용한 코드 리팩토링 및 코드 리뷰 역량 강화 방법을 학습한다.

### 학습 목표

- 클린코드, 리팩토링, TDD(테스트 주도 개발)의 개념을 실습하고, 해당 기술들을 실제 프로젝트에 적용할 수 있다.
- 생성형 AI 기반 코드 리팩토링, 디버깅, 테스트 코드를 작성할 수 있다.
- AI를 활용한 코드 리뷰 및 품질을 개선할 수 있다.
- 개발 프로세스 내 AI 활용 지점 파악과 실무 적용 능력을 배양할 수 있다.

### 대상자

SW 중급 개발자 (클린코드, TDD, 리팩토링 기본 내용 이해 개발자), Java 활용 임직원 중 Code Review 역량 강화와 AI 활용에 관심있는 모든 분

## 4. 팀 프로젝트

### 4.1 팀 프로젝트 개요

본 교육 과정은 현업 프로젝트와 유사한 개발 방식으로 Clean Code, TDD, Refactoring 지식을 활용한 요구사항을 구현할 수 있다.

**학습 목표**: 교육 내용의 주도적 활용 및 팀원 간 소통 능력 배양

### 4.2 기본 요구사항

- 직원 관리를 위한 Database를 생성하고 관리하는 프로그램을 구현한다.
- Database에는 직원 번호, 성명, 직급, 전화번호, 생년월일을 포함한다.
- 기타 자세한 내용은 제공되는 요구사항 문서를 참조한다.

### 4.3 진행 방식

**팀 구성**

- 1팀 4~5인

**Repository 규칙**

- Organization 내 팀 프로젝트 진행을 위한 Repository 생성
- Repository명: `TeamProject_팀명` (팀명은 자유)
- Description: `#팀, 참여 이름 필수` (예: `1팀, 홍길동, 박문수, 이순신, 황진희`)

**Code Review 기준**

- 팀 내 Code Review 필수
- Main branch merge 시 Review 필수
- 개발 branch → main branch PR & Review
- Offline review의 Online 기록 권장
- Vote up 개수 등 세부사항은 팀 자율 결정

**TDD 및 브랜치 전략**

- TDD Practice 필수
- Release branch를 만들어 최종 제출

> **결론**: 브랜치 명명 규칙은 `팀명-교육생번호-단계` 형식을 따른다. (예: `A팀-27번 교육생-RED단계`)

**커밋 기준**

- 커밋 별 code change 50줄 이하 권장
